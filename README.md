## 📝 Study Methodology

For every problem in this repository, I follow a strict 3-step process:
1. **Dry Run:** Hand-writing the logic in a physical notebook to track variable states.
2. **Pseudocode:** Writing the logic in plain English before touching the keyboard.
3. **Implementation:** Coding the solution in JS first, then translating it to Java.

## 📂 Project Structure
My repository is organized by language and topic to maintain a clean workspace:

- **`java-dsa/src/`**: Contains Java implementations, categorized by topics like `star patterns` and `arrays`.
- **`javascript-dsa/`**: Contains JavaScript implementations, categorized by topics like `patterns` and `arrays`.
